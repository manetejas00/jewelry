# Veyora catalogue copy

Use this skill together with one Nexscope copy skill when writing jewellery catalogue text for Veyora Jewels.

The storefront is a custom React and Express shop. It is not Shopify, Amazon, Etsy, eBay, Walmart, or TikTok Shop. Write for that storefront and for Google. Prices are in INR. Gold-linked prices change with the approved metal rate, so copy must not state a rupee price.

## Facts you may use

Only these stored fields: name, category, description, metal, purity, net weight in grams, size, finish, and SKU. There is no structured diamond shape, carat, colour, clarity, cut, polish grade, symmetry grade, certificate, or natural-versus-lab-grown field.

## Claims you must not add

Do not introduce hallmarking, certification, laboratory names, carat weight, colour, clarity, cut grade, polish grade, symmetry grade, or lab-grown or natural-diamond status unless that exact claim is already present in the supplied product text. Do not name the supplier. Do not change metal, purity, weight, size, stock, or price.

## Publish boundary

Generated text is a draft. A merchant approves a name, a description, or both before either replaces the live catalogue.
