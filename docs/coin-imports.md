# Coin CSV imports

Admin → Coins → Import coins (also under Imports). Download the blank template or export the current coin catalogue, edit it, choose the CSV, review prices and stock, then confirm publication. A failed file does not change the catalogue. Error CSVs and batch history use the existing Imports screen. Examples are fictional, draft-only SKUs; never publish them as actual inventory.

Keep the exact template header order. One supplier per file; keep an existing SKU’s supplier. SKU must be unique across coins and jewellery. Required values include supplier, SKU, name, metal (Gold/Silver), type, purity, positive grams, making charge, pricing mode, stock, publication status, image kind and UTC source timestamp. Amounts are unformatted INR decimals, stock is a non-negative integer. METAL_LINKED uses current metal rates and pricing rules; leave fixed_price blank. FIXED requires a positive fixed_price. Status is published/draft; image_kind is photo/illustration. Images accept HTTPS or local /uploads/ and /assets/ paths. Source timestamps use YYYY-MM-DDTHH:mm:ss.sssZ.

Imports update coin details, pricing, stock and images. Stock is a snapshot at source_timestamp; paid coin quantities after that timestamp are deducted during publication. Export uses current stock and a fresh snapshot timestamp, so it can safely round trip. Older snapshots, supplier changes and jewellery SKU collisions are rejected. Manual coin edits advance the source timestamp. Existing order amounts/items are never rewritten. Identical files/publications are repeat-safe. Preview validates again under a publication lock to reject newer conflicting data.

Default imports are incremental: omitted coins stay unchanged. COIN_INVENTORY_MODE=full zeros missing SKUs only for that supplier. Optional COIN_FEED_URL (HTTPS), COIN_FEED_TOKEN or COIN_FEED_FILE enable scheduled imports using the same validation/publication path. Scheduled workflows include coins only when a coin source is configured; COIN_FEED_ENABLED=false disables it. Manual uploads need none of these settings.
